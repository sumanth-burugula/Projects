AI-assisted clinical-style prospective suspecting system built with Python and FastAPI. The project is designed to demonstrate RAG, agentic workflows, structured outputs, validation/guardrails, observability, Docker, and a React + TypeScript frontend using synthetic data.

[View project](./clinical-ai-platform)

## 2. Distributed Secure Messaging Platform

Real-time distributed messaging system built with Python, FastAPI, REST APIs, and WebSockets. The roadmap includes authentication, persistence, event-driven processing, React + TypeScript, Docker, observability, and automated testing.
